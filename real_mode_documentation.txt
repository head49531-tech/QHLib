RM_KEYWORD_DOCUMENTATION
Real Mode Library (rm.inc)
================================================================================
Version:     1.1
Date:        2026
Library:     rm.inc (corrected v4, with protected mode support)
Scope:       16-bit real mode plus 32-bit protected mode support. Intended
             for boot sectors, two-stage loaders, and the transition to
             protected mode.
Audience:    Systems programmers, OS developers, hobbyist kernel writers.

CHANGES IN v1.1
    * Added Section 12 constants (protected-mode configuration).
    * Added Section 13 macros (protected-mode transition: loadpmode).
    * Added Section 14 macros (32-bit output: pm_halt, pm_clear, pm_print,
      pm_print_at, pm_print_hex_*).
    * Added Section 16 routines (32-bit internals: pm__set_cursor,
      pm__get_cursor, pm__putc, pm__scroll_up, pm__hex_nibble).
    * Added Section 8b internal helpers (rm__kbc_wait_in, rm__kbc_wait_out)
      used by enable_a20_kbc.
    * Added warnings for PM_STACK_TOP (EBDA collision) and loadpmode
      (assembler-mode side effect).
    * Corrected pm_clear's preservation contract: it preserves EAX, ECX,
      EDI (the source comment previously claimed these were clobbered).
    * Added PM_A20_METHOD semantics.
    * Added pm_print_at bounds-check and row-clipping behavior.
    * Added PERFORMANCE NOTE for the CRTC round-tripping in pm_print.

HOW TO READ THIS DOCUMENT
--------------------------------------------------------------------------------
Every public symbol in rm.inc is listed here in one of four categories:

    MACRO     A preprocessor macro. Expands inline at the call site. No call
              is generated, no return address is pushed. Cheap.

    CONSTANT  A %define. Pure text substitution. Uppercase by convention.

    ROUTINE   A label with a `ret`. Reached via `call`. Emitted once per
              translation unit (guarded).

    INTERNAL  A symbol whose name begins with `rm__` or `pm__`. Not part of
              the public API. Present so the reader can understand what the
              library does at a low level. Do not call these from user code
              unless you know exactly what you are doing.

Conventions used throughout:

    Preserves: registers whose value is unchanged on return. If a register
               is not in the Preserves list, its value is undefined.
    Clobbers:  registers whose value is destroyed.
    Flags:     either "undefined on exit" (assume all flags are meaningless)
               or "preserved" (unusual — most routines do not preserve flags).
    DF:        Direction Flag. Every string operation in this library begins
               with `cld`, so callers do not need to pre-clear it.

SECTION 1 — CONFIGURATION CONSTANTS
================================================================================
These are evaluated at assembly time. Every one can be overridden by a
`%define` before `%include "rm.inc"`. The `%ifndef` guard means an existing
definition wins.

LOAD_ADDR                                             [CONSTANT]
    Default: 0x7C00
    The address the boot sector is loaded to by the BIOS. Used by `sof` as
    the ORG value and by `setupstack` as the initial stack pointer. Override
    only if you are writing a non-boot-sector component that is loaded at a
    different address.

BOOTSIG                                               [CONSTANT]
    Default: 0xAA55
    The magic word the BIOS looks for at offset 510 of a boot sector. Written
    by the `bootloader` macro.

PT                                                    [CONSTANT]
    Default: 510
    The offset (from the start of the image) where the boot signature must
    appear. Exposed so you can compute it or replace it if you are producing
    a non-standard image.

SECTOR_SIZE                                           [CONSTANT]
    Default: 512
    Bytes per disk sector. Informational; the library does not currently use
    it for arithmetic.

STACK_ADDR                                            [CONSTANT]
    Default: LOAD_ADDR (0x7C00)
    The initial value loaded into SP by `setupstack`. The stack grows down
    from this address.

KERNEL_SEG                                            [CONSTANT]
    Default: 0x1000
    Suggested real-mode segment for the second-stage kernel image.
    Informational; not used by any routine.

KERNEL_OFF                                            [CONSTANT]
    Default: 0x0000
    Suggested offset paired with KERNEL_SEG. Informational.

KERNEL_SECTORS                                        [CONSTANT]
    Default: 64
    Suggested sector count for the second-stage image. Informational.

SECTION 10 — TEXT OUTPUT MACROS (16-BIT REAL MODE)
================================================================================

print                                                     [MACRO]
    Signature:  print "string literal"
    Purpose:    Prints a null-terminated string. The string is embedded
                inline in the code segment immediately after a short jump.
                Printing is done via BIOS int 0x10, AH=0x0E (teletype).
                A 0x0A in the literal is translated to CR+LF.
    Notes:      Uses a `cs:` override for the string read, so DS does not
                matter. BH is set to 0 (video page 0) before every
                teletype call.
    Preserves:  AX, SI
    Clobbers:   BH (always set to 0), flags undefined
    DF:         cleared before the read loop
    Size:       One embedded string plus roughly 20 bytes of code per call.

print_at_si                                               [MACRO]
    Signature:  print_at_si
    Purpose:    Prints the null-terminated string pointed to by DS:SI.
                Same 0x0A -> CR+LF translation and BH handling as `print`.
    Preserves:  none
    Clobbers:   AX, SI, BH, flags undefined
    DF:         cleared before the read loop

print_char                                                [MACRO]
    Signature:  print_char
    Purpose:    Prints the character in AL using BIOS teletype.
    Preserves:  none
    Clobbers:   AH, BH, flags undefined

print_nl                                                  [MACRO]

    Preserves:  AX
    Clobbers:   BH, flags undefined

print_hex_byte                                            [MACRO]

print_hex_word                                            [MACRO]

    Preserves:  AX, BX, CX, DX
    Clobbers:   BH, flags undefined

print_dec                                                 [MACRO]

SECTION 14 — A20 GATE MACROS

enable_a20                                                [MACRO]
    Signature:  enable_a20
    Purpose:    Enables the A20 address line via system control port 0x92
                ("fast A20"). Fastest method; works on nearly all hardware
                manufactured after 1995.
    Preserves:  AX
    Clobbers:   flags undefined
    Notes:      On very old hardware or certain chipsets, this can silently
                fail. For reliability, use enable_a20_kbc as well, or use
                pm.inc's PM_A20_METHOD = 3 which does both.

enable_a20_kbc                                            [MACRO]
    Signature:  enable_a20_kbc
    Purpose:    Enables A20 using the keyboard controller method. Slower
                than fast A20 but more compatible. Preserves the entire
                output-port byte, unlike some naive implementations.
    Preserves:  AX, BX, IF (interrupt-enable state)
    Clobbers:   flags (restored)
    Notes:      Executes cli/popf around the sequence. Uses the internal
                helpers rm__kbc_wait_in and rm__kbc_wait_out.

rm__kbc_wait_in                                           [INTERNAL]
    Signature:  rm__kbc_wait_in (macro, no arguments)
    Purpose:    Spins until the keyboard controller's input buffer is empty
                (status bit 1 clear).
    Preserves:  none
    Clobbers:   AL, flags
    Notes:      No timeout. Will spin forever if the KBC never clears the
                input-buffer-full bit — which should not happen on
                functioning hardware.

rm__kbc_wait_out                                          [INTERNAL]
    Signature:  rm__kbc_wait_out (macro, no arguments)
    Purpose:    Spins until the keyboard controller's output buffer is full
                (status bit 0 set).
    Preserves:  none
    Clobbers:   AL, flags
    Notes:      No timeout. Same caveat as rm__kbc_wait_in.

SECTION 16 — PROTECTED MODE CONFIGURATION CONSTANTS
================================================================================
These constants are used by the protected-mode portion of the library
(Sections 17 and 18). They can be overridden by a %define before including
rm.inc.

PM_CODE_SEL                                           [CONSTANT]
    0x08
    The GDT selector for the flat 32-bit ring-0 code segment installed by
    `loadpmode`. After the transition, CS = 0x08.

PM_DATA_SEL                                           [CONSTANT]
    0x10
    The GDT selector for the flat 32-bit ring-0 data segment installed by
    `loadpmode`. After the transition, DS = ES = FS = GS = SS = 0x10.

PM_STACK_TOP                                          [CONSTANT]
    Default: 0x90000
    The 32-bit stack grows down from this address. `loadpmode` loads it
    into both ESP and EBP.
    WARNING: 0x90000 is a heuristic, not a guarantee. On some systems the
    Extended BIOS Data Area (EBDA) begins as low as 0x80000, in which case
    the first 32-bit push silently overwrites it. Override before including
    rm.inc if you target such systems, or read the EBDA segment at physical
    address 0040:000E at runtime and choose a stack top below it.

PM_A20_METHOD                                         [CONSTANT]
    Default: 1
    Selects how `loadpmode` enables the A20 address line.
        1  Fast A20 via port 0x92. Default. Works on nearly all systems.
        2  Keyboard controller method. Slower, more compatible.
        3  Both. Belt-and-suspenders; slowest.
    Setting any value other than 1, 2, or 3 causes a %error at assembly
    time.

PM_VGA_BASE                                           [CONSTANT]
    0xB8000
    Physical address of the VGA text buffer, as seen from flat 32-bit
    protected mode.

PM_VGA_COLS                                           [CONSTANT]
    80
PM_VGA_ROWS                                           [CONSTANT]
    25
PM_VGA_SIZE                                           [CONSTANT]
    PM_VGA_COLS * PM_VGA_ROWS = 2000
PM_VGA_ATTR                                           [CONSTANT]
    0x07
    Default attribute used by the protected-mode output routines.

SECTION 17 — PROTECTED MODE TRANSITION
================================================================================

pm__enable_a20                                        [INTERNAL]
    Signature:  pm__enable_a20 (macro, no arguments)
    Purpose:    Expands the A20-enable sequence selected by PM_A20_METHOD.
                Emits nothing if PM_A20_METHOD is invalid (a %error is
                raised first).
    Preserves:  depends on the selected method; see enable_a20 and
                enable_a20_kbc.
    Clobbers:   depends on the selected method.

loadpmode                                                 [MACRO]
    Signature:  loadpmode entry_label
    Purpose:    The complete 16-bit real mode -> 32-bit protected mode
                transition.

    Performs, in order:
        1. cli                — disables interrupts (no IDT is installed)
        2. A20 enable         — according to PM_A20_METHOD
        3. lgdt [rm__gdtr]    — loads the built-in flat GDT
        4. set CR0.PE         — enters protected mode
        5. far jump           — flushes the pipeline, loads CS = 0x08
        6. 32-bit stub        — loads DS/ES/FS/GS/SS = 0x10, sets ESP and
                                EBP = PM_STACK_TOP, jumps to entry_label

    Built-in GDT layout (emitted once per translation unit, guarded by
    RM_GDT_EMITTED):
        0x00  null
        0x08  32-bit code, base 0, limit 4 GB, DPL 0
        0x10  32-bit data, base 0, limit 4 GB, DPL 0

    Register state on entry to entry_label:
        CS = 0x08, DS = ES = FS = GS = SS = 0x10
        ESP = EBP = PM_STACK_TOP
        EAX = undefined
        EBX/ECX/EDX/ESI/EDI = preserved from real mode (upper halves zeroed
                              by the operand-size change)
        EFLAGS = undefined (IF cleared)

    ASSEMBLER STATE WARNING:
        loadpmode toggles `bits 32` for its inline stub and then restores
        `bits 16`. NASM's `bits` directive is a global, source-order toggle,
        not scoped to the macro body. As a consequence, after loadpmode is
        expanded the assembler is in `bits 16` mode regardless of what it
        was before. This is correct for the intended usage (caller is
        already in bits 16). If you invoke loadpmode from a bits 32 context
        — unusual and generally wrong — you must re-issue `bits 32`
        afterwards.

    IMPORTANT: execution never returns to the 16-bit caller. Place your
    32-bit code in a `bits 32` section and pass its label.

    Preserves:  EBX, ECX, EDX, ESI, EDI
    Clobbers:   EAX, CS, DS, ES, FS, GS, SS, ESP, EBP, EFLAGS
    Does not return.

    Space cost: ~30 bytes for the transition stub, ~30 bytes for the GDT
    and GDTR. Budget ~64 bytes in your boot sector.

================================================================================
SECTION 18 — 32-BIT PROTECTED MODE OUTPUT MACROS
================================================================================
All macros in this section are intended to be expanded inside `bits 32`
code, with the flat CS/DS layout that `loadpmode` installs. BIOS int 0x10
is unavailable; output goes directly to the VGA text buffer.

PERFORMANCE NOTE:
    pm_print and pm__putc round-trip the VGA CRTC on every character to
    keep the hardware cursor in sync. Port I/O to the CRTC is slow — each
    `out` to 0x3D4/0x3D5 has microsecond-scale latency on real hardware,
    and pm__putc performs several per character. This is appropriate for
    boot-stage console output (a few dozen lines), not for high-throughput
    text. A faster variant would cache the cursor offset in a register or
    memory variable between calls.

pm_halt                                                   [MACRO]
    Signature:  pm_halt
    Purpose:    Disables interrupts, halts the CPU, re-halts on spurious
                wakeups. Does not return.
    Preserves:  n/a
    Clobbers:   n/a

pm_clear                                                  [MACRO]
    Signature:  pm_clear attribute_byte
    Purpose:    Fills the VGA text buffer with spaces of the given
                attribute and resets the hardware cursor to offset 0,0.
    Preserves:  EAX, ECX, EDI
    Clobbers:   flags undefined
    DF:         cleared
    Notes:      The source comment previously stated "Clobbers EAX, ECX,
                EDI"; that was incorrect. The macro pushes and pops all
                three, so it preserves them. This documentation reflects
                the actual behavior.

pm_print                                                  [MACRO]
    Signature:  pm_print "string literal"
    Purpose:    Prints a null-terminated string literal at the hardware
                cursor. Handles LF (0x0A) as a line break, CR (0x0D) as a
                no-op, wraps at column 80, and scrolls when the last row
                is reached.
    Preserves:  EBP
    Clobbers:   EAX, EBX, ECX, EDX, ESI, EDI, flags undefined
    Notes:      Calls pm__putc for each character. See the PERFORMANCE
                NOTE at the top of this section.

pm_print_at                                               [MACRO]
    Signature:  pm_print_at row, column, "string literal"
    Purpose:    Prints a string literal at a fixed row/column. Does not
                touch the hardware cursor.
    Constraints:
        row    must be in 0..24
        column must be in 0..79
    If row or column is out of range, a %error is raised at assembly time.
    The string is clipped at the end of the target row: at most
    (PM_VGA_COLS - column) characters are written, so a long string cannot
    bleed into the next row.
    Preserves:  EBX, EDX, EBP
    Clobbers:   EAX, ECX, ESI, EDI, flags undefined

pm_print_hex_byte                                         [MACRO]
    Signature:  pm_print_hex_byte
    Purpose:    Prints AL as two uppercase hex digits at the hardware
                cursor.
    Preserves:  EAX
    Clobbers:   EBX, flags undefined

pm_print_hex_word                                         [MACRO]
    Signature:  pm_print_hex_word
    Purpose:    Prints AX as four uppercase hex digits.
    Preserves:  EAX
    Clobbers:   EBX, flags undefined

pm_print_hex_dword                                        [MACRO]
    Signature:  pm_print_hex_dword
    Purpose:    Prints EAX as eight uppercase hex digits.
    Preserves:  EAX
    Clobbers:   EBX, flags undefined

SECTION 19 — EMIT-ONCE ROUTINES
================================================================================
These are actual code, emitted the first time rm.inc is included in a
translation unit. They are guarded so that multiple inclusions do not
cause duplicate symbol errors. Across object files, the symbols are local
to each object, so linking is also safe.

--- 16-bit real-mode routines ---

rm__hex_nibble                                            [INTERNAL]
    Signature:  call rm__hex_nibble with low nibble in AL
    Purpose:    Prints the low nibble of AL as one uppercase hex digit via
                BIOS teletype. Internal helper for print_hex_*.
    Preserves:  AL
    Clobbers:   AH, BH, flags
    Notes:      Uses `jb` (unsigned) after comparing AL to 10.

--- 32-bit protected-mode routines ---
These are only reachable after loadpmode has installed the flat GDT and
set the segment registers accordingly.

pm__set_cursor                                            [INTERNAL]
    Signature:  call pm__set_cursor with linear text offset in AX (0..1999)
    Purpose:    Writes the VGA hardware cursor position via the CRTC ports
                0x3D4/0x3D5.
    Preserves:  EAX, EBX, EDX
    Clobbers:   flags undefined

pm__get_cursor                                            [INTERNAL]
    Signature:  call pm__get_cursor
    Purpose:    Reads the VGA hardware cursor position. Returns the linear
                text offset (0..1999) in AX.
    Preserves:  EBX, EDX
    Clobbers:   EAX (as the return channel), flags undefined

pm__putc                                                  [INTERNAL]
    Signature:  call pm__putc with character in AL
    Purpose:    Writes AL to the VGA text buffer at the hardware cursor,
                advances the cursor, wraps at column 80, and scrolls when
                the last row is reached. LF (0x0A) moves to the start of
                the next row; CR (0x0D) is ignored.
    Preserves:  EAX, EBX, ECX, EDX, ESI, EDI
    Clobbers:   flags undefined
    Notes:      Reads the cursor, writes the cell, updates the cursor. See
                the PERFORMANCE NOTE in Section 18.

pm__scroll_up                                             [INTERNAL]
    Signature:  call pm__scroll_up
    Purpose:    Scrolls the VGA text buffer up by one row: rows 1..24 are
                copied to rows 0..23, and the bottom row is filled with
                blank cells using PM_VGA_ATTR.
    Preserves:  EAX, ECX, ESI, EDI
    Clobbers:   flags undefined
    Notes:      Does not modify the hardware cursor.

pm__hex_nibble                                            [INTERNAL]
    Signature:  call pm__hex_nibble with low nibble in AL
    Purpose:    Prints the low nibble of AL at the hardware cursor via
                pm__putc. Internal helper for pm_print_hex_*.
    Preserves:  EAX
    Clobbers:   flags undefined

================================================================================
APPENDIX A — CALLING CONVENTIONS
================================================================================
Registers are used in a simple, traditional way, not per any modern ABI:

    * Argument passing: by register, documented per macro. No stack args.
    * Return values:    in AL, AX, DX, DH, or via a pointer the caller
                        set up.
    * Preserved:        whatever each macro's documentation says. Nothing
                        else is guaranteed.
    * Flags:            destroyed by anything that calls BIOS. Do not rely
                        on flags surviving a macro unless the macro
                        explicitly says "flags preserved."
    * Direction Flag:   cleared by every macro that uses a string
                        operation. You do not need to execute cld before
                        calling a library routine.

================================================================================
APPENDIX B — MULTI-FILE SAFETY
================================================================================
The emit-once routine is guarded by %ifndef so it is emitted at most once
per translation unit. NASM emits labels as file-local symbols unless they
are explicitly declared `global`, so linking two object files that both
include rm.inc does not produce duplicate-symbol errors.

================================================================================
APPENDIX C — OVERRIDING CONFIGURATION
================================================================================
Every configuration constant is wrapped in %ifndef. To change one, define
it before including the library:

    %define LOAD_ADDR 0x0600
    %include "rm.inc"

================================================================================
APPENDIX D — SIZE AND PERFORMANCE
================================================================================
Approximate sizes of the emitted routines:

    rm__hex_nibble          ~20 bytes
    print (per call site)   ~20 bytes of code + string length + 1
    clear_screen            ~25 bytes inlined
    print_dec               ~40 bytes inlined
    pm__set_cursor          ~30 bytes
    pm__get_cursor          ~30 bytes
    pm__putc                ~60 bytes
    pm__scroll_up           ~40 bytes
    pm__hex_nibble          ~20 bytes
    loadpmode (per call)    ~30 bytes + ~30 bytes for GDT + GDTR

================================================================================
APPENDIX E — ERROR HANDLING
================================================================================
The library does not define error codes. Routines that issue BIOS calls
propagate the BIOS's own return convention:

    * Disk functions set CF=1 on error, AH=status.
    * Keyboard functions always succeed in blocking mode; the non-blocking
      poll uses ZF to indicate "no key."
    * Video functions have no failure mode in normal operation.

================================================================================
APPENDIX F — WHAT THIS LIBRARY DOES NOT DO
================================================================================
    * No filesystem support. Disk reads are raw sector reads.
    * No memory map parsing (E820). Constants are provided; parsing is not.
    * No long-mode entry. See pm.inc for long mode.
    * No serial output. See lm.inc.
    * No keyboard layout translation. The BIOS supplies ASCII directly.
    * No mouse, no joystick, no sound.
